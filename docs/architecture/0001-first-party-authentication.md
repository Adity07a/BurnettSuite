# ADR 0001: Central first-party suite authentication

Status: accepted for the current migration phase.

## Decision

BurnettSuite will not introduce an external social-login or OIDC provider in
the current phase. The platform exposes one login request with two supported
identifiers:

```json
{"identifier":"email address or mobile number","password":"..."}
```

Email matching is case-insensitive. Mobile numbers are stored without spaces,
parentheses, dots, or hyphens and may include a leading country-code `+`.

Interview and Resume inherit Django's username database column. Removing it now
would require a destructive identity migration and could break foreign-key and
admin behavior. New usernames are therefore random internal keys generated by
the server; they are excluded from public registration, login, and profile
responses. BurnettPeople already uses an email-native user model with no
username field.

## Session boundary

- Interview temporarily owns credentials and issues a suite JWT in HttpOnly
  access and refresh cookies.
- The signing key and cookie contract are shared by all three backends.
- Resume and People validate the suite token and provision a bounded local user
  on first access. Their domain data and migrations remain independent.
- Product login and registration pages redirect to the platform routes.
- A shared header exposes all products and the current login/logout state.

## Data ownership

Credential ownership is centralized, while domain profiles remain in their
product databases. Email is the stable cross-product identity claim. Automatic
provisioning is idempotent and never copies a password into a product database.

## Follow-up

Before replacing Interview with a dedicated identity service:

1. Export normalized email/mobile collision reports from all products.
2. Define People employee assignment beyond the initial Suite Member profile.
3. Define account linking, recovery, suspension, and deletion policies.
4. Add key rotation and explicit audience/issuer validation before public
   production rollout.
